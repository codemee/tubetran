## 本版重點 / Highlights

- **新增：Windows 11 上，滑鼠停在最大化鈕時會彈出「貼齊版面」選單。** 可以直接挑選要把視窗排到螢幕的哪個位置。最大化鈕停留時的灰底在選單出現期間會維持。Windows 10 沒有這個選單，行為不變。

- **調整：最大化改用系統的最大化。** 以前是程式自己把視窗鋪滿工作區；現在由系統處理，還原時會回到最大化之前的位置與大小。Windows 11 上視窗左、右、下多了系統的細邊框，邊緣也可以直接拖曳縮放。最大化鈕上不再顯示提示文字。

- **New: on Windows 11, resting the pointer on the maximize button opens the Snap Layouts flyout.** Pick where on the screen the window should go. The button keeps its grey highlight while the flyout is open. Windows 10 has no such flyout and behaves as before.

- **Changed: maximize now uses the system maximize.** The app used to fill the work area itself; the system now does it, and restoring returns to the position and size from before maximizing. On Windows 11 the window gains a thin system border on the left, right and bottom, and those edges can be dragged to resize. The maximize button no longer shows a tooltip.
