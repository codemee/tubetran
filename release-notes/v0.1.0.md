## 本版重點 / Highlights

**第一個公開版本。** 貼上 YouTube 網址，就能邊看影片邊看 Claude 翻譯的繁體中文雙語字幕。

- **字幕來源：** 優先下載 YouTube 字幕（人工字幕優先，其次自動字幕）；沒有字幕時，下載音檔並用本機 Whisper 語音辨識。
- **翻譯：** 以 Claude API 翻成繁體中文（台灣用語），連影片標題一起翻；每批翻完就存檢查點，中斷後可接著翻，翻譯中已翻好的句子就能先使用。
- **播放：** 字幕疊在影片上、全螢幕也看得到，可切換雙語／原文／譯文，並可匯出 SRT／VTT。
- **影片庫：** 列出已翻譯、翻譯中、中斷的影片，記錄上次播放位置；可搜尋標題，也可加標籤篩選。
- **字幕檢查：** 合併重複、修正時序、補翻空白譯文。
- **設定面板：** 在介面輸入 Claude API 金鑰、選擇翻譯模型與語音辨識（STT）模型，不必改環境變數。
- **兩種執行方式：** 桌面應用程式（無框視窗、支援多螢幕）與伺服器模式（`--server`）。
- 淺色／深色主題、繁體中文／英文介面。
- 可用 `uv tool install` 安裝，並提供 Windows 執行檔 ZIP。

**The first public release.** Paste a YouTube URL and watch the video with Traditional Chinese bilingual subtitles translated by Claude.

- **Subtitle source:** YouTube captions first (manual, then auto-generated); when there are none, the audio is downloaded and transcribed locally with Whisper.
- **Translation:** translated to Traditional Chinese (Taiwan usage) with the Claude API, including the title; a checkpoint is saved after every batch so an interrupted run resumes, and translated lines are usable while translation is still running.
- **Playback:** subtitles are overlaid on the video, also in fullscreen; switch between bilingual / original / translation, and export SRT / VTT.
- **Library:** lists translated, in-progress and interrupted videos and remembers the playback position; search titles and filter by tags.
- **Subtitle check:** merges duplicates, fixes timing and fills in blank translations.
- **Settings panel:** enter your Claude API key and pick the translation and speech-to-text (STT) models in the UI, no environment variables needed.
- **Two ways to run:** a desktop app (frameless window, multi-monitor aware) and a server mode (`--server`).
- Light and dark themes, Traditional Chinese / English interface.
- Installable with `uv tool install`, with a Windows executable ZIP.
