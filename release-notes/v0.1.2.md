## 本版重點 / Highlights

- **修正：從網路下載的 Windows ZIP 解壓縮後打不開桌面視窗。** 下載的檔案會被 Windows 標記成「來自網際網路」而封鎖，導致桌面視窗無法啟動（錯誤訊息類似 `Failed to resolve Python.Runtime.Loader.Initialize`）。現在程式啟動時會自動清除這個標記；若仍然失敗，會用對話框說明解法，而不是一長串錯誤訊息。
- 如果你用的是 0.1.1 以前的版本遇到這個問題，請升級，或對 ZIP 按右鍵 →「內容」→「解除封鎖」後再解壓縮。

- **Fix: the desktop window would not open from a Windows ZIP downloaded from the internet.** Windows marks downloaded files as "from the internet" and blocks them, so the desktop window failed to start (errors like `Failed to resolve Python.Runtime.Loader.Initialize`). The program now clears that mark on startup, and if it still fails it explains the fix in a dialog instead of a long traceback.
- If you hit this on 0.1.1 or earlier, upgrade, or right-click the ZIP → Properties → Unblock before extracting.
