## 本版重點 / Highlights

- **文件修正：** 用 `uv tool install` 安裝時必須指定 `--python 3.12`（或 `3.13`），否則在較新的 Python 上會因語音辨識套件尚無對應版本而安裝失敗。README 與 PyPI 頁面都已補上說明。程式本身沒有改動。

- **Docs fix:** installing with `uv tool install` requires `--python 3.12` (or `3.13`); on newer Pythons the install fails because the speech-recognition package has no matching wheels yet. The README and the PyPI page now say so. No change to the program itself.
