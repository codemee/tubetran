## 本版重點 / Highlights

- **更新內部使用的音訊解碼元件 `av`（18.1.0 → 18.1.1）。** 原本的 18.1.0 已被作者撤回：解碼某些特殊聲道配置的音訊時，可能發生記憶體損毀。這只影響沒有字幕、要用 Whisper 轉錄的影片，而且要遇到特殊的音訊才會發生；其他功能與使用方式都沒有變。
  - Windows ZIP 與 macOS DMG 以前是照鎖定檔打包，所以會帶到被撤回的版本，這版起改帶 18.1.1。用 PyPI 安裝的人不受影響：安裝工具預設會跳過被撤回的版本。

- **Updated the audio decoding component `av` (18.1.0 → 18.1.1).** 18.1.0 has been withdrawn by its author: decoding audio with certain unusual channel layouts could corrupt memory. This only affects videos without captions that are transcribed with Whisper, and only when such unusual audio is met; nothing else changes.
  - The Windows ZIP and macOS DMG are built from the lock file, so they used to ship the withdrawn version; from this release on they ship 18.1.1. Installs from PyPI are not affected: installers skip withdrawn versions by default.
