## 本版重點 / Highlights

- **新增：匯出／匯入，把翻好的影片帶到其他電腦。** 播放器下方的「匯出」匯出目前這支影片，影片庫上方的「匯出全部」匯出所有已翻譯的影片；檔名用影片的譯名，好辨認。到另一台電腦按影片庫上方的「匯入」（可一次選多個檔案），影片連同播放位置、標籤一起出現；已經有的影片會略過、不覆蓋。匯出檔不含音檔，觀看不需要 API 金鑰。
- **新增：字幕模式「無」（練聽力）。** 影片上不顯示字幕，下方的字幕清單仍是雙語，聽完可以對照。
- **新增：投影片模式。** 影片停在某則字幕的時間點，用播放區左右的 ‹ › 按鈕（或 ← →、PageUp／PageDown，簡報遙控器也可以）逐則切換，左上角顯示「第幾則／共幾則」。注意：YouTube 嵌入播放器的播放鈕、標題列等介面無法隱藏。
- **改變：YouTube 原字幕一律隱藏**，不再提供選項（本來就是用我們的字幕取代它）。
- **修正：桌面版的「下載 SRT／VTT」沒有反應。** 現在會跳出「另存新檔」對話框，檔名也改用影片的譯名。

- **New: export / import to take translated videos to another computer.** "Export" below the player exports the current video, and "Export all" at the top of the library exports every translated video; files are named after the video's translated title so they are easy to recognise. On the other computer press "Import" at the top of the library (you can pick several files); the videos appear together with playback position and tags, and videos already there are skipped, not overwritten. Exports contain no audio, and no API key is needed to watch.
- **New: subtitle mode "None" (listening practice).** No subtitles on the video, while the subtitle list below stays bilingual so you can check afterwards.
- **New: slide mode.** The video stays on one subtitle's moment, and you step through subtitles with the ‹ › buttons on either side of the player (or ← →, PageUp / PageDown, so presentation clickers work too); the top left shows "current / total". Note: the YouTube embedded player's play button, title bar and similar overlays cannot be hidden.
- **Changed: YouTube's own captions are always hidden**; the option is gone (our subtitles replace them anyway).
- **Fixed: "Download SRT / VTT" did nothing in the desktop app.** It now shows a "Save as" dialog, and the file is named after the video's translated title.
