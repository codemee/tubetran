## 本版重點 / Highlights

- **修正：英文影片被拿去翻譯別人上傳的俄文字幕。** 以前只要影片有任何人工字幕就直接採用，即使語言不是影片本身的語言（例如英文影片只有一軌他人上傳的俄文字幕），結果變成「英文 → 俄文 → 中文」。現在人工字幕只採用影片本身語言；沒有的話改用該語言的自動字幕，再沒有才用 Whisper 語音辨識。
- 已經用錯字幕翻好的影片，需要刪除快取後重新翻譯才會套用。

- **Fix: English videos were translated from someone else's Russian captions.** Any manual caption track used to be accepted even in another language (for example an English video whose only manual track was an uploaded Russian one), giving English → Russian → Chinese. Manual captions are now used only when they are in the video's own language; otherwise the auto-generated captions in that language are used, and Whisper only as a last resort.
- Videos already translated from the wrong track need their cache deleted and to be translated again.
