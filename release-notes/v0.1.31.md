## 本版重點 / Highlights

- **修正：取消正在翻譯的影片後，播放器下方的訊息會一直顯示「已要求取消」。** 取消要等背景任務做完目前這一步才會真的結束；以前任務結束後，這則訊息沒有更新，看起來像是還在取消。現在取消完成時，訊息會換成「已取消，並清除這支影片的快取」。如果取消後你已經改看別支影片，就不會再蓋掉你當下的訊息。

- **Fixed: after cancelling a video that is being translated, the message under the player kept saying "Cancel requested".** A cancel only takes effect after the background task finishes its current step; the message was never updated once it had, so it looked as if it were still cancelling. When the cancel completes, the message now becomes "Cancelled; the cache for this video was removed". If you have already moved on to another video, your current message is not overwritten.
