## 本版重點 / Highlights

- **新增：匯出目前篩選。** 影片庫套用標籤、「無標籤」或搜尋篩選後，上方會多一顆「匯出目前篩選」按鈕，只匯出篩選結果裡已翻譯完成的影片。
- **新增：設定面板分頁。** 分成「一般」與「快捷鍵」；「快捷鍵」列出所有快捷鍵，清單固定高度、自己捲動。
- **修正：** 編輯標籤時輸入框不再疊到右上角的按鈕、黃色焦點外框也不再被裁掉。
- **移除：** 影片項目上的「檢查字幕」按鈕（翻譯完成時本來就會自動檢查）。

- **New: export the current filter.** Once a tag, "No tags" or search filter is applied in the library, an "Export current filter" button appears and exports only the fully translated videos in the filtered result.
- **New: settings panel tabs.** General and Shortcuts; Shortcuts lists every keyboard shortcut in a fixed-height list that scrolls on its own.
- **Fixed:** while editing tags, the input no longer overlaps the buttons at the top right, and its yellow focus ring is no longer clipped.
- **Removed:** the "Check subtitles" button on library items (subtitles are already checked automatically when translation finishes).
