## 本版重點 / Highlights

- **Windows 版 ZIP：下載後不用再「解除封鎖」，也不再於啟動時修改你的資料夾。** 從 GitHub 下載的 ZIP，檔案會被 Windows 標記成「來自網際網路」，.NET 因此拒絕載入桌面視窗需要的元件。以前程式啟動時會逐一刪除這些標記；現在改成在 `TubeTran.exe` 旁附一個 `TubeTran.exe.config`，直接告訴 .NET 允許載入。
  - 好處：程式不再修改資料夾裡的檔案，放在唯讀的資料夾也能開啟。
  - 請保留 `TubeTran.exe.config`，不要刪掉，也不要只複製 `TubeTran.exe` 到別處。
  - 發布前會對最後的 ZIP 做驗證：替每個檔案加上網路來源標記後真的開出視窗，並有拿掉設定檔的對照組，確認這個測試抓得到問題。
  - 這只影響 Windows 的 ZIP 版；PyPI 安裝、macOS、瀏覽器模式都不受影響。

- **Windows ZIP: no more "Unblock" after downloading, and the app no longer modifies your folder at startup.** Files from a ZIP downloaded from GitHub are marked by Windows as "downloaded from the Internet", so .NET refuses to load the components the desktop window needs. The app used to delete those marks one by one at startup; it now ships a `TubeTran.exe.config` next to `TubeTran.exe` that tells .NET to allow loading them.
  - Benefit: the app no longer modifies files in its folder, and it opens from a read-only folder too.
  - Please keep `TubeTran.exe.config`: don't delete it, and don't copy only `TubeTran.exe` elsewhere.
  - Before release, the final ZIP is verified: every file is marked as downloaded from the Internet and the window really has to open, with a control (config removed) to confirm the test can catch the problem.
  - This only affects the Windows ZIP; PyPI installs, macOS and browser mode are not affected.
