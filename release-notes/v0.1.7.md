## 本版重點 / Highlights

- **修正：譯文位移。** 一句話被切成好幾段字幕時，模型有時會把後面片段的內容提前翻進前一句，造成後面的句子重複、變成「……」或「（註：此句為原文片段）」。現在的提示詞要求每句譯文只對應該句原文，一句話被切成幾段，中文也照斷點切成幾段。
- 已翻譯的舊影片要刪除快取後重新翻譯才會套用。

- **Fix: shifted translations.** When one sentence was split across several caption lines, the model sometimes pulled text from later fragments into the previous line, leaving later lines duplicated, empty ("……") or reading "(note: this is a fragment)". The prompt now requires each translation to cover only its own source line, splitting the Chinese at the same breakpoints.
- Videos translated earlier need their cache deleted and to be translated again.
