## 本版重點 / Highlights

- **新增：Linux 無標題列視窗。** Linux 桌面模式（`desktop-qt`）現在和 Windows 一樣沒有系統標題列，視窗按鈕畫在頁首右上角；拖曳頁首空白處或左上角圖示移動視窗（X11、Wayland 都可以），雙擊最大化／還原，視窗邊緣可縮放。不想要的話加 `--native-titlebar`。
- **修正：Linux 關閉視窗後終端機回不到 shell。** 現在視窗關閉後會直接結束程式。
- **視窗標題依語系同步：** 英文語系下標題為 TubeTran，中文為「水管譯工」。

- **New: frameless window on Linux.** Desktop mode on Linux (`desktop-qt`) now has no system title bar, like Windows; the window buttons are drawn at the top right of the header. Drag an empty part of the header or the icon to move the window (works on both X11 and Wayland), double-click to maximize/restore, drag the edges to resize. Add `--native-titlebar` if you don't want this.
- **Fixed: the terminal did not return to the shell after closing the window on Linux.** The program now exits right after the window closes.
- **The window title follows the language:** TubeTran in English, 水管譯工 in Chinese.
