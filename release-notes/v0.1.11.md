## 本版重點 / Highlights

- **改善：字幕改成「一句一則」，譯文不再錯位。** 自動字幕常斷在句子中間（例如 "across mount" / "views."），以前逐段翻譯時，譯文會被提前塞進前一段，之後每段都錯開一格。現在先把片段重組成完整的句子再翻譯（太長的句子在逗號處切開），原文與譯文都是整句，閱讀更順。
- **改善：整支影片的術語前後一致。** 翻譯前先讀完全部字幕整理術語表（例如 namespace 保留英文、process 一律譯為「行程」），每一批翻譯與影片標題都照表翻；每批也會附上前後幾句當參考，批次交界的句子接得上。
- **改善：影片上的長字幕折成長度接近的兩行**，盡量斷在標點之後，不再出現「第一行很長、第二行只有一兩個字」。
- **新增：影片庫的 ↻ 重新處理。** 丟掉目前的翻譯，重新取得字幕並以整句重新翻譯（觀看進度與標籤保留）。舊版翻譯的影片可以用它改成一句一則。
- **新增：字幕清單跟著播放位置。** 展開時直接跳到正在播放的那句並標示出來；自己捲動瀏覽時暫停跟隨，按「回到目前字幕」即可回來。
- **修正：無字幕影片的語音辨識失敗**（`TypeError: open() got an unexpected keyword argument 'metadata_errors'`）。
- **修正：無字幕影片下載音檔偶爾出現「HTTP Error 403: Forbidden」。** 電腦上有 deno／node／bun 時會自動用來解 YouTube 的驗證，並且失敗時自動重試。
- **文件：** README 新增「把翻好的影片搬到其他電腦」。

- **Improved: one sentence per subtitle, so translations no longer drift.** Auto-captions often break mid-sentence (e.g. "across mount" / "views."); translating fragment by fragment used to pull text into the previous fragment and shift every following line by one. Fragments are now regrouped into whole sentences before translation (overly long ones are split at a comma), so both the original and the translation read as complete sentences.
- **Improved: consistent terminology across the whole video.** Before translating, TubeTran reads the full transcript and builds a glossary (e.g. keep "namespace" in English, always translate "process" the same way); every batch and the title follow it, and each batch also gets a few neighbouring sentences for context so lines at batch boundaries connect.
- **Improved: long subtitles on the video are wrapped into two lines of similar length**, breaking after punctuation where possible, instead of a long first line and one or two words on the second.
- **New: ↻ Reprocess in the library.** Discards the current translation, fetches captions again and retranslates sentence by sentence (watch progress and tags are kept). Use it to convert videos translated by older versions.
- **New: the subtitle list follows playback.** When expanded it jumps straight to the line being played and highlights it; scrolling yourself pauses following, and "Back to current line" brings you back.
- **Fixed: speech recognition failing for videos without captions** (`TypeError: open() got an unexpected keyword argument 'metadata_errors'`).
- **Fixed: occasional "HTTP Error 403: Forbidden" when downloading audio for videos without captions.** If deno / node / bun is installed it is used to solve YouTube's challenge, and failed downloads are retried automatically.
- **Docs:** the README now explains how to move translated videos to another computer.
