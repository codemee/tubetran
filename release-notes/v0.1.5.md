## 本版重點 / Highlights

- **修正：macOS 上程式無法執行。** 原本有一個 Windows 專用的模組在 macOS 上匯入就會失敗；現在 macOS 可以正常執行（從原始碼或 `uv tool install`）。
- **macOS 也支援全螢幕**，全螢幕鈕同樣會跟著 YouTube 控制列自動隱藏；用系統方式（綠色按鈕、選單）退出全螢幕時，播放區也會跟著還原。

- **Fix: the program could not run on macOS.** A Windows-only module failed to import there; macOS now works (from source or with `uv tool install`).
- **Fullscreen now works on macOS too**, and the fullscreen button auto-hides together with YouTube's controls; leaving fullscreen the system way (green button, menu) also restores the player.
