## 本版重點 / Highlights

- **新增：macOS App（Apple 晶片）。** 現在每個版本都會附上 `TubeTran-*-macos-arm64.dmg`，開啟後拖進「應用程式」即可，不需要安裝 Python。沒有 Intel 版；App 沒有簽章也沒有公證，第一次開啟需要手動允許（做法見 README）。
- **macOS 圖示：** 改為透明背景、內容約佔 70% 的圖示，Dock 上的大小與其他 App 一致。

- **New: macOS app (Apple silicon).** Every release now ships `TubeTran-*-macos-arm64.dmg`: open it and drag TubeTran into Applications, no Python needed. There is no Intel build; the app is neither signed nor notarized, so you have to allow it manually the first time (see the README).
- **macOS icon:** a transparent background with the content at about 70%, so it looks the same size as other apps in the Dock.
